# Thrust Land Proto

纯网页最小玩法验证：可切换机体（方块多喷口 / 细长单喷口）+ 单指喷气，验证「按住调姿 → 落地」手感。

**无 Unity / 无美术 / 无关卡 / 无广告。** 与 Sort 工程完全独立。

当前版本：**v11**

## 可玩

- **GitHub Pages**：https://ninja9998877.github.io/thrust-land-proto/
- 本地：浏览器直接打开 `index.html`
- 备用：https://raw.githack.com/ninja9998877/thrust-land-proto/main/index.html

## v11 要点

- **姿态–推力耦合**：喷气默认沿机体纵轴；指尖相对机体的屏幕水平偏移只做万向偏转（≤maxAngle）。倾斜后按住喷气会产生水平速度，可调姿对准落点
- 重力仍为世界向下；积分仍用世界坐标 `vx,vy`（不再把推力绑成屏幕竖直）
- 继承 v7–v10：单指、无冷却、屏幕坐标重投影、简洁星空、尾流、一镜到底、小地图、燃料+随机倾角、禁长按、`1`/`2`/`R`

## 操作

| 输入 | 作用 |
|------|------|
| 单指按住并拖动 | 绑定最近喷口并喷气（可在底栏喷气区） |
| 鼠标左键拖动 | 同上（右键无效） |
| `1` / `2` | 切换「方块·多喷口 / 细长·单喷口」并复位 |
| `R` | 回到约 3000 m、随机倾角、燃料加满 |

橙色线=排气（沿机体轴±偏转），青色线=对机体的力。右上小地图：绿十字=落点，黄三角=火箭。

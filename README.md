# Thrust Land Proto

纯网页最小玩法验证：长方形机体 + 底边密集喷口喷气，验证「按住调姿 → 落地」手感。

**无 Unity / 无美术 / 无关卡 / 无广告。** 与 Sort 工程完全独立。

当前版本：**v5**

## 可玩

- **GitHub Pages**：https://ninja9998877.github.io/thrust-land-proto/
- 本地：浏览器直接打开 `index.html`
- 备用：https://raw.githack.com/ninja9998877/thrust-land-proto/main/index.html

## v5 要点

- 默认推力 **90**（约为 v4 的一半；滑条仍可调高）
- **多层视差背景**：远星 / 色带 / 云层 / 近山 / 近景网格，由相机位置驱动 offset；下落与平移时相对地面与机体有清晰滑动
- 地面仍世界锁定

## v4 玩法（保留）

- 镜头跟随机体（世界坐标 + 相机平滑）
- 开局约 **3000 m** 自由落体（1 世界单位 ≈ 1 m）
- HUD 显示离地高度（**机体最低角点**到地面 `groundY` 的距离）
- 屏幕下方约 25%（≥140px）为喷气指控留白；地面画在可玩视口底之上
- 底边 **9** 个等距喷口；按住后滑动会**实时重绑**最近空闲喷口
- 多指各绑不同喷口；推力仍：按下点↔喷口连线、偏角≤上限、力反向
- v3 稳态（阻尼 / 扭矩 / omega 上限）

## 操作

| 输入 | 作用 |
|------|------|
| 触屏按住并拖动 | 每指绑定最近空闲喷口并喷气（可在底栏喷气区） |
| 鼠标左键 / 右键 | 各占一喷口（可同时） |
| `R` 或右上角「复位」 | 回到约 3000 m、姿态清零 |

橙色线=排气，青色线=对机体的力。

## 参数（右上角）

- **推力**（默认 90）：单口推力大小
- **偏角°**（默认 60）：相对机体向下轴的最大偏转
- **重力**（默认 55）
- **阻尼**（默认 0.35）：线速度阻尼

## 文件

- `index.html` — 单页自含（Canvas 2D + 简易刚体），无构建、无依赖

## 成功标准

打开即可玩；自由落体可见高度下降与背景视差滑动；按住拖动能换喷口调姿并尝试落地。

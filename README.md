# Thrust Land Proto

纯网页最小玩法验证：长方形机体 + 底边密集喷口喷气，验证「按住调姿 → 落地」手感。

**无 Unity / 无美术 / 无关卡 / 无广告。** 与 Sort 工程完全独立。

当前版本：**v6**

## 可玩

- **GitHub Pages**：https://ninja9998877.github.io/thrust-land-proto/
- 本地：浏览器直接打开 `index.html`
- 备用：https://raw.githack.com/ninja9998877/thrust-land-proto/main/index.html

## v6 要点（抖落地对策）

- **总燃料有限**：喷气消耗燃料；耗尽无法再喷；HUD 显示剩余% + 条；`R`/复位加满。量级：认真控姿大致够落地，左右快抖连续喷会很快耗尽
- **单口冷却**：换绑/松开喷口后该口约 **150ms** 无法出推力（首触不冷却；多指仍可绑不同口）
- **开局随机倾角**：reset 时姿态约 **±15°～±45°**，不再竖直白送
- 背景视差保持 v5，未再改

## v5 保留

- 默认推力 **90**
- 多层视差背景（相机驱动）
- 镜头跟随、开局约 **3000 m**、高度 HUD、底指控留白、**9** 喷口、拖动重绑最近喷口
- v3 稳态（阻尼 / 扭矩 / omega 上限）

## 操作

| 输入 | 作用 |
|------|------|
| 触屏按住并拖动 | 每指绑定最近空闲喷口并喷气（可在底栏喷气区） |
| 鼠标左键 / 右键 | 各占一喷口（可同时） |
| `R` 或右上角「复位」 | 回到约 3000 m、随机倾角、燃料加满 |

橙色线=排气，青色线=对机体的力；冷却中喷口变灰，绑定但未喷为淡连线。

## 参数（右上角）

- **推力**（默认 90）：单口推力大小
- **偏角°**（默认 60）：相对机体向下轴的最大偏转
- **重力**（默认 55）
- **阻尼**（默认 0.35）：线速度阻尼

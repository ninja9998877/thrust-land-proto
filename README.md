# Thrust Land Proto

纯网页最小玩法验证：长方形机体 + 双喷口喷气，验证「按住调姿 → 落地」手感。

**无 Unity / 无美术 / 无关卡 / 无广告。** 与 Sort 工程完全独立。

## 可玩

- 本地：用浏览器打开 `index.html`（或任意静态服务器根目录）
- GitHub Pages：见仓库 Settings → Pages（`main` / `/`）

## 操作

| 输入 | 作用 |
|------|------|
| 触屏 1～2 指按住 | 每指绑定最近且空闲的喷口，喷气 |
| 鼠标左键 | 第一喷口 |
| 鼠标右键 | 第二喷口（可同时按住） |
| `R` 或右上角「复位」 | 重置姿态与位置 |

按下点与绑定喷口的连线为**排气方向**（相对机体局部「向下」钳制 ≤ 偏角上限，默认 **60°**）；机体受力为排气反方向。底边左右各一喷口。橙色线=排气，青色线=对机体的力。

## 参数（右上角）

- **推力**（默认 180）：单口推力大小
- **偏角°**（默认 60）：相对机体向下轴的最大偏转
- **重力**（默认 55）
- **阻尼**（默认 0.15）：线速度阻尼

喷口位置：机体中心为原点时，底边左右约 `x=±18`、`y=+0.48×身高`（身高默认 96px）。

## 文件

- `index.html` — 单页自含（Canvas 2D + 简易刚体），无构建、无依赖

## 成功标准

打开即可玩；双指/左右键可同时喷；落地可弹/停，重在手感。

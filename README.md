# Thrust Land Proto

纯网页最小玩法验证：可切换机体（方块多喷口 / 细长单喷口）+ 单指喷气，验证「按住调姿 → 落地」手感。

**无 Unity / 无关卡 / 无广告。** 与 Sort 工程完全独立。现含烟头皮美术 drop-in。

当前版本：**v17**

## 操作

| 输入 | 作用 |
|------|------|
| 单指按住并拖动 | 指在机体下方→底喷口；上方→顶喷口；拖动瞄准 |
| 鼠标左键拖动 | 同上（右键无效） |
| 右上切换按钮 | 「方块·多喷口 / 细长·单喷口」并复位 |
| 右上「重置 (R)」 | 回到约 3000 m、随机倾角、燃料加满 |
| `1` / `2` | 同上（键盘） |
| `R` | 同上（键盘） |

橙色线=底喷排气，青色线=顶喷排气；火星/烟灰粒子叠加。底部小地图：绿十字=落点（烟灰缸），黄三角=机体。

## 文件

- `index.html` — 单页自含（Canvas 2D + 简易刚体），无构建、无依赖
- `assets/` — 烟头皮 PNG（机体 / 烟灰缸落点 / 开场手 / 火星 FX）

## 成功标准

打开即可玩；两种机体均有顶+底喷口；指侧选喷口银行；自由落体带随机倾角且沿姿态斜落；燃料条随喷气下降；落地镜头连贯；小地图可对落点。
